The list lives in a private GitHub repo. This page reads and ticks it with a token that stays in this browser only (localStorage); nothing goes anywhere but api.github.com.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Repository access → Only select repositories → .
  3. Permissions → Repository → Contents: Read and write. Expiry: a year. Generate.
  4. Paste it here.
